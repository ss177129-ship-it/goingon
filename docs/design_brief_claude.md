# 고잉온(GoingOn) 디자인 브리프 — Claude 디자인 세션용

> 이 문서 하나로 디자인 작업에 필요한 맥락을 전부 담았다. 함께 첨부된 `prototype_v2.html`은 기존 화면의 비주얼 DNA 참고용이다(간격·라운딩·타이포의 실물 예시).

## 1. 제품

**멀리 있어도, 발이 맞는 순간을 만든다** — 사운드 리듬 기반 커뮤니케이션형 러닝 앱(iOS).
핵심 철학: **"기록이 아니라 관계."** Strava식 퍼포먼스 경쟁이 아니라, 떨어져 있는 두 사람이 발을 맞추는 감각을 판다. 동시에 달리는 것은 정점이지 전제조건이 아니다 — 혼자 달려도 관계에 쌓이고, 겹치면 터진다.

- **케이던스가 심장**: 곡의 BPM이 내 발걸음을 실시간으로 따라온다. 들리는 발소리는 상대의 것만.
- **공명(resonance)**: 두 사람의 케이던스가 맞아떨어지는 순간. 제품의 가장 희소한 보상.
- **8분 에피소드**: 시간 기반 세션(거리 아님). 완결 내장. 끝나면 잔향 30초 — 계속 뛰면 자유런으로 이어짐.
- **고스트런 = 시차 동행**: 상대의 과거 러닝 리듬과 함께 달린다. 추월 게임이 아니다.
- **러닝 중 화면 조작 제로**: 시작 후 종료까지 화면을 보거나 만질 필요가 0이어야 한다. 세션 화면은 조작판이 아니라 방송판.

## 2. 디자인 토큰 (확정 — 변경 불가)

### 컬러
| 토큰 | HEX | 용도 |
|---|---|---|
| paper | `#F0EAE0` | 기본 배경 |
| canvas | `#EBE4D6` | 카드/서브 배경 |
| lime | `#C5E040` | **나** |
| limeDark | `#6A9810` | 나(텍스트/진한 변형) |
| coral | `#F05840` | **상대** |
| coralDark | `#B03020` | 상대(진한 변형) |
| ink | `#1A1A16` | 본문/제목 |
| resonance | `#D4A84B` | **공명 전용 골드** |
| amber | `#D97706` | 경고/강조 보조 |
| mid | `#78746E` | 보조 텍스트 |
| dim | `#B0ACA6` | 약한 텍스트/섹션 라벨 |
| line | `rgba(26,26,22,.09)` | 구분선 |

**컬러 의미 규칙(절대 규칙): 나 = lime, 상대 = coral, 공명 = 골드 전용.** 섞지 말 것. kcal 등 일반 지표는 ink/mid. 골드가 "우리 둘이 만든 것"이라는 희소성을 가지려면 공명 외에 절대 쓰지 않는다.

### 타이포
- 타이틀/숫자: **Instrument Serif italic** (Google Fonts에 있음 — HTML 시안에서 로드 가능)
- 본문: **Noto Sans KR**
- Instrument Serif에는 한글 글리프가 없다 — 세리프 타이틀에 한글이 섞이면 Noto Sans KR로 폴백된다는 전제로 디자인할 것
- 섹션 라벨: 11px / weight 600 / letter-spacing 1.2 / dim

### 레이아웃
- 카드 라운딩 18~22px, 화면 좌우 여백 22~28px
- 무드: 따뜻한 종이 질감, 아날로그 감성. 네온·다크테크·게임 UI 아님

## 3. 금지 사항 (디자인에 직접 걸리는 것)

1. **이모지 금지** — 인앱 렌더링에서 깨진다. Material Icons, 커스텀 벡터, 기하 기호(▲ ● ★)만 사용
2. **승패·순위·앞서기/뒤처지기 언어 금지** — UI 카피 포함. 쓰는 말은 **가까워짐 / 나란함 / 멀어짐** 셋뿐. 리더보드·랭킹 UI 금지
3. **러닝 중 화면 조작을 요구하는 UI 금지** — 세션 화면의 조작 요소는 일시정지 하나만
4. **수익화 UI 금지** — 결제·구독 관련 화면·버튼 일절 넣지 않음
5. **죄책감 카피 금지** — "스트릭 잃어요!" 류. 알림·CTA는 기대감 문법만

## 4. 이번에 디자인할 화면 (P5~P6)

기준 와이어프레임: 피그마 01~07 (https://www.figma.com/design/koizbsGLUZofes4nXNahux)

### 온보딩 4장
1. **여덟 걸음** — 가입 전, 폰 들고 제자리 여덟 걸음 → 걸음이 비트가 되는 30초 체험(최초의 아하)
2. **데모런 제안(60초)** — "가상의 페이서예요" 명시된 가상 동반자와 공명의 느낌 학습
3. **레벨 질문 1개** — "달리기 어느 정도 하세요?" → 홈 기본값 분기
4. **초대 제안** — "같이 뛰고 싶은 사람, 한 명쯤 있잖아요. 링크 하나면 끝" (건너뛰기 가능)

### 홈 2종 (레벨 분기)
- **입문자형**: '오늘의 8분'(에피소드) 전면
- **경험자형**: 자유런 전면
- 공통 카드 3장 구조: 오늘의 에피소드 / 지금 뛰는 중(존재 레이어) / 우리 여정
- **오늘의 상대 카드**(고스트런 1막): 그날의 맥락 — 거리·시간대·페이스 곡선·사연 한 줄

### 세션(러닝 중) 화면
- 조작 제로 원칙 — 정보 방송판. 일시정지만
- 공명 순간의 비주얼(골드)이 유일한 "사건" 표현
- 야외 직사광·야간 가독성 검토 필요(다크 변형 논의 대상)

### 완주 후 결과 화면 (컴포넌트 순서 고정)
1. **오늘 만든 트랙 ▶** — 내 리듬으로 렌더링된 1분 음원. 화면의 주인공
2. 함께 요약 — 공명 초·응원 수·상대
3. 여정 지도 — 오늘이 놓인 자리
4. 거리·페이스·케이던스 — **접힘**(기록은 있되 조연)
- 액션 3개: 한 마디 보내기 / 카드 공유(인스타 스토리 규격) / 내일 예고

## 5. 디자인 과제 (부족한 층)

1. **그래픽 언어** — 일러스트·모션 스타일이 없다. 온보딩이 팔아야 하는 개념(여덟 걸음·공명·시차 동행)은 전부 추상이라 커스텀 벡터/모션 한 벌이 필요
2. **세션 화면 조도** — paper 크림 배경의 야외/야간 가독성, 다크 변형 여부
3. **앱 밖 그래픽** — 앱 아이콘, 공유 카드(인스타 스토리 규격, 성장 엔진의 핵심), 스토어 스크린샷
