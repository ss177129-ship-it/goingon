## 0. 관통 원칙 — 모든 화면·기능의 헌법

### 원칙 1. 러닝 중 화면 조작 제로

【결정】 러닝 시작 후 종료까지 유저가 화면을 봐야 하거나 터치해야 하는 순간을 0으로 만든다.
【맥락】 달리며 폰을 꺼내는 행위는 러닝의 흐름(플로우)을 깨고, 낙상·충돌 위험을 만들며, "러닝 경험의 본질을 잃지 말라"는 외부 피드백의 핵심이었다. 리듬세상이 눈 감고도 플레이되듯, 우리의 인터페이스는 귀·발·이어폰 꼭지 세 개다.
【동작】 모든 선택(에피소드, 상대, 모드)은 시작 전에 끝낸다. 러닝 중 입력은 ① 이어폰 꼭지 1회 누름(문맥적 예/아니오 — 예: 체인 수락) ② 꼭지 길게 누름(워키토키 녹음) ③ 발(케이던스 변화 = 시스템이 읽는 입력) 세 가지뿐. 러닝 중 화면은 켜면 보이는 정보(케이던스·진행)만 있고 조작 요소는 일시정지뿐.
【엣지】 전화 수신 시 세션 자동 일시정지 → 통화 종료 후 "이어갈까요?" 음성 안내 + 꼭지 1회로 재개. 신호등 등 30초 미만 정지는 일시정지로 치지 않고 리듬 일시 이탈로 처리(음악 레이어만 얇아짐).

### 원칙 2. 러닝의 본질을 침범하지 않는다

【결정】 사운드는 러닝을 돕는 배경이다. 러닝을 사운드의 소재로 쓰지 않는다.
【맥락】 친구 피드백 — "런닝이라는 본질적 경험을 잃지 말라." 몰입 장치가 과하면 러닝앱이 아니라 러닝을 구실로 한 게임이 된다. 우리의 차별점은 러닝 중을 채우는 것이지 러닝을 대체하는 것이 아니다.
【동작】 사운드 총량에 상한을 둔다: 화자 발화는 에피소드당 6문장 이내, 연속 발화 금지(문장 사이 최소 40초), 유저가 "조용한 모드"(화자 없음, 음악만)를 선택 가능. 주변음 투과(transparency) 모드 기본 권장.
【엣지】 이어폰 없이 시작한 경우 → 사운드 없는 트래킹 모드로 동작(세션·여정 기록은 동일 인정).

### 원칙 3. 소셜 = 세션의 문 또는 산출물

【결정】 그 자체로 소비되고 끝나는 소셜 표면은 만들지 않는다. 모든 소셜 요소는 세션으로 들어가는 입구이거나 세션에서 나온 산출물이어야 한다.
【맥락】 인스타·스트라바의 피드는 종착지(스크롤로 소비 종료)다. 우리는 체류시간이 아니라 러닝을 팔므로, 소셜의 성공 기준 자체를 "세션 유발량"으로 정의한다.
【동작】 기능 추가 심사 시 두 질문을 통과해야 한다: "이것이 다음 러닝을 만들어내는가?" 또는 "이것이 방금 러닝에서 나온 것인가?" 둘 다 아니오면 만들지 않는다. (예: 전체 인기 랭킹 — 탈락. 러닝 카드의 [함께 뛰기] — 통과.)

### 원칙 4. 세계관은 유저의 것

【결정】 우리는 터·연장·의례를 만들고, 전설은 관계가 쓴다.
【맥락】 CEO 정의 — "우리는 그들의 세계관을 창조하도록 돕는 사람." 세계관을 우리가 다 쓰면(풀 좀비런 노선) 주인공 자리를 NPC가 차지하고 1인팀은 콘텐츠 공장이 된다. 비워두면(풀 인스타 노선) 문화가 경쟁·과시로 흐른다. 그래서 동사(의례)는 우리가, 명사(사람·사연)는 유저가.
【동작】 authored 최소 세트: 페이서 1명, 에피소드 10개, 시드 고스트 100개, 의례 4종(릴레이·사연 한 마디·사운드 응원·여정). 기능 심사 기준: "이 기능이 그들의 전설(첫 공명 날짜, 그들만의 코스, 그들만의 농담)을 만드는 데 기여하는가."

## 1. 사운드 시스템 (D안)

### 1-1. 음악 엔진 — "곡이 나를 따라온다"

【결정】 재생되는 음악의 템포(BPM)가 유저의 케이던스(spm)에 실시간 동기화된다. 유저 본인의 발소리는 기본 무음.
【맥락】 러너는 자기 발소리·호흡을 고유수용감각으로 이미 느낀다. 내 스텝의 소리화는 중복 피드백이며 통화 에코처럼 거슬릴 수 있다(친구 가설, 우리도 6:4로 동의). 대신 "곡이 나를 따라온다"는 템포 추종만으로도 '내가 음악을 조종한다'는 체감은 성립한다.
【동작】
- 케이던스 검출: 가속도계 기반, 3초 이동 평균으로 스무딩(순간 튐 방지).
- BPM 매핑: 곡 BPM = 케이던스 × 1.0, 유효 범위 140~190으로 클램프. 걷기(120 이하) 구간은 하프타임(케이던스 ÷ 2 배속) 렌더링으로 어색함 방지.
- 레이어 규칙: L1 드럼(항상) → L2 베이스(케이던스 표준편차가 60초간 임계 이하 = '안정' 판정 시) → L3 화성·멜로디(공명 시 또는 안정 3분 지속 시). 흐트러지면 위 레이어부터 역순으로 얇아진다 — 잔소리 대신 소리의 밀도로 상태를 알림.
- '내 발소리' 토글: 설정에서 ON 시 내 스텝이 곡의 퍼커션으로 추가(C안 문법). 기본 OFF. ※ 프로토타입 A/B 테스트로 기본값 최종 확정(검증 큐 #1).

### 1-2. 상대의 소리 — "들리는 발걸음은 상대의 것만"

【결정】 세션에 상대(고스트/라이브)가 있으면 상대의 발걸음 소리가 내 곡 안에 들린다. 음색은 나와 구분되는 우드 톤.
【맥락】 함께의 실감은 내 소리가 아니라 상대의 실재에서 온다. 상대 발소리는 그 사람의 실제 기록 리듬(합성 아님)이어야 감정이 실린다 — 오르막에서 느려진 그대로.
【동작】
- 렌더링: 상대 케이던스 데이터(초 단위 타임라인)를 수신하고, 발소리 샘플은 내 기기에서 로컬 합성(네트워크 지연 100~300ms에 강건 — 걸음을 스트리밍하지 않고 리듬만 동기화).
- 정위: 풀 바이노럴 3D 금지(전정-청각 충돌 멀미 리스크 — 친구 피드백 채택). 좌우 게인 차이만: 상대 소리 약 60:40으로 오른쪽 우세. 모노 모드 옵션 제공.
- 거리감: 케이던스 차이가 클수록 상대 소리 볼륨·선명도 하락("멀어짐"), 가까워지면 상승. 앞서기/뒤처지기 언어는 UI 어디에도 쓰지 않는다(§3-1 대원칙).

### 1-3. 공명 판정

【결정】 두 사람의 케이던스가 맞물리면 '공명' — 화성 레이어가 만개하고 청명한 벨이 울린다.
【맥락】 리듬세상의 '퍼펙트' 판정이 주는 신체적 쾌감을 함께의 순간에 이식한다. 이 순간이 제품의 아하 모먼트다.
【동작】
- 판정: |내 케이던스 − 상대 케이던스| ≤ 3spm 상태가 8초 지속 → 공명 진입. 조건 이탈 10초 지속 → 공명 해제(페이드, 실패음 없음 — 벌은 없다).
- 정수비 허용: 2:3, 1:2 등 정수비 관계도 폴리리듬 공명으로 인정(페이스가 달라도 함께라는 약속의 구현).
- 보상: 진입 순간 벨 + 화성 만개 + (첫 공명이면) 화자 명명 — "발이 맞았어요. 이게 고잉온이에요." 세션당 공명 누적 초가 기록됨.
【지표】 7일 내 첫 공명 도달률(북극성 입력 1), 세션당 공명 시간.

### 1-4. 워키토키

【결정】 이어폰 꼭지를 누르는 동안만 녹음되는 짧은 음성 조각. 연속 통화는 영구 배제.
【맥락】 연속 통화는 창업자가 직접 실패를 검증한 방식(바람 소리, 숨참, 상태 모름). 그러나 인간의 목소리가 주는 온기는 필요하다(친구 피드백). 절충 = 문장 단위 교환.
【동작】 길게 누름 → 녹음(최대 15초) → 손 떼면 상대에게 전송. 상대 세션 중이면 곡 사이에 재생, 아니면 DM 스레드에 쌓임. 바람 소리 억제 필터 적용. 수신 빈도 상한(분당 2개)으로 스팸 방지.
【엣지】 고스트런 중 워키토키 → 상대의 '그날'에는 전달 불가하므로 DM으로 배달 + "시차 배달" 라벨.

## 2. 세션 시스템

### 2-1. 세션 정의

【결정】 세션 = 8분 에피소드. 시간 기반, 완결 내장, 상한 아님, 전 유저 공통 규격. 자유런 병존.
【맥락】 ① 거리 단위는 페이스 차별적(빠른 사람의 1km=5분, 입문자=9분)이라 '같은 것을 함께'가 깨진다. 시간은 평등하며 공유 가능하다. ② 사운드·서사는 시간 매체다(절정을 6분 지점에 설계하려면 길이를 알아야 함). ③ 건강 근거(JACC 2014: 하루 5~10분)도 시간 단위. ④ 입문 러너의 기브업 포인트가 1km(6~8분)라는 CEO의 크루런 현장 관찰 — 에피소드의 끝을 그 지점에 놓아 포기를 완주로 반전시킨다. ⑤ 전원 공통 규격은 매칭·고스트 호환·약속의 네트워크 효과를 만든다.
【동작】 에피소드 채보 = 동사 5종(홀드·콜&리스폰스·스퍼트·템포체인지·릴레이)의 배열 + 시나리오 스킨. 표준 아크: 인트로(0~1분, 브리지 재생) → 빌드(1~4분) → 미션(4~6분) → 절정(6~7.5분) → 아웃트로(~8분).
【엣지】 8분 미만 중단 시: 4분 이상이면 "부분 완주"로 여정에 거리 인정(스트릭은 미인정), 4분 미만은 기록만 저장. 중단에 실패 사운드·문구 없음 — "오늘은 여기까지. 내일 이어서요."

### 2-2. 모드 구조 — 입구는 분리, 출구는 연속

【결정】 시작 시 에피소드런/자유런을 명시적으로 선택한다. 러닝 중 모드 전환 UI는 없다. 에피소드의 끝에서만 자유런으로 이음새 없이 이어진다.
【맥락】 시작의 의도가 선명해야 경험이 선명하다(기승전결의 약속 vs 열린 동행의 약속). 그러나 에피소드 종료 지점에 벽을 세우면 러너스 하이를 죽이고, 입문자가 경험자로 자라는 통로("이왕 나온 김에")를 막는다. 문은 두 개, 복도는 하나.
【동작 — 잔향 판정 로직】
1. 8:00 도달 → 음악 해소 + "완주예요" → 잔향 상태 진입(음악이 낮게 유지되는 30초 판정 구간).
2. 판정 구간 중 케이던스 ≥ 140 유지 → 자유런으로 자동 전환(그루브가 다시 차오름, 멘트 없음). 화자가 1회만 제안: "다음 화로 이어가려면 꼭지를 한 번." 꼭지 1회 = 다음 에피소드 체인.
3. 케이던스 < 120(걷기 전환) 10초 지속 → 세션 종료 시퀀스(§5).
4. 자유런 진입 후 추가 프롬프트 금지. 8분마다 은은한 마디 종소리(옵션).
【엣지 — 동반자 퇴장 의례】 고스트의 기록이 끝나면: "지수의 그날은 여기까지였어요" + 발소리 페이드. 라이브 상대가 먼저 종료하면: 상대의 종료 화면에 "응원 남기고 나가기" 원탭 → 내 귀에 "지수가 먼저 들어가면서 응원을 남기고 갔어요." 단절이 아니라 작별 인사로.
【지표】 잔향 연장률, 체인 선택률 vs 자유런 전환률(= "8분이 짧다" 가설의 실증 데이터).

### 2-3. 경험자 대응 (예: 6km/60분 러너)

【결정】 경험자의 기본 모드는 자유런. 에피소드는 긴 러닝의 마디(오프닝·앙코르)로 쓰인다.
【맥락】 입문자의 결핍은 "러닝이 부담"(→ 8분 완결이 약), 경험자의 결핍은 "함께의 부재"(→ 연결 레이어가 약). 연결 레이어(공명·고스트·응원·여정)는 러닝 길이를 가리지 않으므로 제품 하나로 두 결핍을 다 다룬다.
【동작】 온보딩 질문 1개("달리기, 어느 정도 하세요?")로 홈 기본값 분기: 입문자 = "오늘의 8분" 전면, 경험자 = 자유런 전면 + 에피소드 추천 카드. 콘서트 구조 제안: 오프닝 에피소드 8분 → 자유런 → 앙코르 에피소드 8분.
【부수 효과】 경험자의 안정된 리듬은 입문자의 최고 고스트("20년째 새벽마다 뛰는 러너의 리듬") — 경험자는 자유런만 해도 아카이브의 공급자가 된다. 알림: "당신의 리듬과 함께 달린 사람 12명."

## 3. 고스트런 — 시차 동행

### 3-1. 대원칙

【결정】 고스트런은 추월 게임이 아니라 시차 동행이다. UI·사운드·카피 전체에서 승패·순위·앞서기/뒤처지기 언어를 금지하고 가까워짐/나란함/멀어짐만 쓴다.
【맥락】 스트라바의 과거-나 대결과의 카테고리 구분선. "이겼나?"가 아니라 "함께였나?"를 묻는 것이 우리 문법이다. 경쟁 언어가 한 군데라도 들어오면 기록이 부끄러운 1차 세그먼트가 밀려난다.

### 3-2. 데이터 모델

【결정】 모든 러닝은 자동으로 고스트가 된다(공개 범위: 나만/페이스메이트만/모두, 기본 = 페이스메이트만).
【동작】 고스트 1건 = 케이던스 타임라인(1초 해상도) + 페이스 곡선 + 사연 한 마디(쿨다운 음성, §5) + 워키토키 조각(타임스탬프) + 메타(날짜·시간대·거리·코스는 선택 공개). GPS 경로는 고스트 재생에 불필요(시간축 기반) — 프라이버시 기본값: 경로 비공개.
【맥락 — 시간축 기반인 이유】 "멀리 있어도"가 성립하려면 장소 독립이어야 한다. 지수가 도림천을 뛰었어도 나는 내 동네에서 그날의 리듬과 함께 뛴다. 같은 코스면 "같은 길 겹침" 배지(보너스일 뿐 조건 아님).

### 3-3. 3막 동작

【1막 — 선택】 홈 "오늘의 상대" 추천 우선순위: ① 페이스메이트의 최근 러닝(안부 가치) ② 나의 과거(연속성) ③ 사연 고스트 큐레이션(발견). 카드에는 그날의 맥락 — 페이스 곡선 미리보기 + 사연 한 마디.
【2막 — 재생】 상대 리듬은 내 페이스와 무관하게 그날의 시간축 그대로 재생. 상대가 느려진 구간에서 화자 한 줄(최대 2회/세션): "여기서 지수가 힘들었나 봐요." 시차 공명 판정은 §1-3과 동일. 상대의 음성 조각은 해당 타임스탬프에 재생.
【3막 — 루프】 종료 시 상대에게 알림: "찬웅이 네 화요일 저녁 리듬과 함께 달렸어 — 시차 공명 14초." 알림에서 원탭 응원 → 응원은 찬웅의 다음 러닝 시작에 재생(브리지). ※ 알림 빈도 상한: 동일인으로부터 일 3회 묶음 처리.
【지표】 고스트런 비중, 시차 공명 도달률, 알림→응원(답장) 전환율.

## 4. Day 0 — 친구도 과거도 없는 유저

### 4-1. 문제의 지도

【맥락】 콜드스타트의 최저점: 친구 0, 과거 러닝 0, (런칭 초기엔) 아카이브도 얇음. 동반자 후보는 논리적으로 5종뿐 — ① 지금 달리는 낯선 사람 ② 과거의 낯선 사람 ③ 과거의 나 ④ 가상 ⑤ 총량의 기척. 원칙: **Day 0의 함께란 '아는 사람'이 아니라 '진짜 사람'의 실재감이다**(라디오 사연 문법 — 모르는 이의 사연에도 위로받는다).

### 4-2. 온보딩 시퀀스

【동작】
1. 첫 실행 → 가입 전에 소리 먼저: "폰을 들고 제자리에서 여덟 걸음" → 걸음이 비트가 되는 것을 30초 체험(최초의 아하).
2. 데모런 제안(60초): 페이서(명시된 가상 — "가상의 페이서예요")와 함께 공명의 느낌을 학습.
3. 가입(간편) → 러닝 레벨 질문 1개 → 권한 요청은 맥락 시점에(동작 권한은 데모런 직전, 알림 권한은 첫 완주 직후 — "응원이 오면 알려드릴까요?").
4. 초대 제안 1회: "같이 뛰고 싶은 사람, 한 명쯤 있잖아요. 링크 하나면 끝" — 건너뛰기 가능, 죄책감 카피 금지.
5. 첫 진짜 러닝 = 첫 러닝 릴레이(§4-3).

### 4-3. 첫 러닝 릴레이

【결정】 신규 유저의 첫 8분 상대는 "앞서 시작한 누군가의 첫 8분"이다. 완주하면 내 첫 8분이 다음 신규 유저의 첫 동반자가 된다.
【맥락】 같은 처지(서툴고 흔들리는 첫 리듬)의 동행은 위로가 되고, 완주 즉시 "받는 사람 → 주는 사람" 전환이 일어나 친구 없이도 소속감이 성립한다. 신규 유저가 곧 콘텐츠가 되므로 콜드스타트가 자가 소멸한다.
【동작】 할당: 최근 첫 러닝 풀에서 케이던스 유사도 기준 매칭(±10spm). 품질 필터: 2분 미만·이상 데이터 제외. 익명(닉네임 이니셜만). 완주 후: "이제 당신의 첫 8분이 누군가의 첫 동반자가 됩니다." 이후 내 첫 러닝과 달린 사람이 생기면 알림: "당신의 첫 러닝과 함께 달린 사람이 생겼어요"(원탭 응원 가능, 상호 동의 시 페이스메이트 제안).
【지표】 첫 러닝 완주율, 릴레이 알림 수신 후 재방문율.

### 4-4. 기타 Day 0 장치

- 시드 고스트 100개: 런칭 전 실제 러닝 녹음(베타 테스터·지인·창업자) + 사연. 제작 아닌 녹음이라 저비용.
- 총량 기척: "오늘 고잉온에서 314번의 러닝" / "지금 3명이 달리는 중"(거짓말 불가능한 숫자만).
- 랜덤매칭(실시간 익명)은 유동성 임계(동시 접속 러너 상시 30명 이상) 도달 후 점화. 그 전에 노출하면 빈 매칭 화면이 외로움을 증폭시킨다. 그때까지 ②(고스트)가 대타 — 과거는 언제나 접속 중이다.
- 코스 = 고스트의 진열대: 코스 페이지에 그 길을 달린 리듬·사연이 쌓임(장소 기반 서랍). 솔로런 코스 기능은 동반자가 아니라 무대로 정의.

## 5. 완주 후 경험 — "짜잔" 이후의 5분

【맥락】 완주 직후는 가장 감정적이면서 손을 못 쓰는(숨참·땀) 순간. 기존 앱은 이 정점을 통계 화면으로 식힌다. 우리는 귀로 착륙시키고, 정점의 진심을 채집하고, 보상은 창작물로 주고, 반응은 다음 러닝으로 이월한다.

【동작 — 시퀀스】
1. **~8:00 아웃트로**: 화성 해소 → 도착 벨 → "완주예요"(귀에서 착륙, 화면 불필요).
2. **쿨다운 걷기 0~2분**: 오디오 디브리핑 — "오늘의 1.2km가 우리 여정 217km 지점에. 지수와 14초 겹쳤어요." 이어서 **음성 한 마디 채집**: "숨 고르면서, 오늘 러닝 어땠어요?" → 꼭지 누르고 말하면 끝(최대 20초). 응답은 선택 — 3회 연속 무응답 시 빈도 자동 하향(주 1회 질문). 이 한 마디가 사연 아카이브·러닝 카드 캡션·릴레이 문구의 단일 공급원이다.
3. **폰을 꺼내면 — 결과 화면**: 컴포넌트 순서 고정 ① 오늘 만든 트랙 ▶(내 리듬으로 렌더링된 1분 음원 — 화면의 주인공) ② 함께 요약(공명 초·응원 수·상대) ③ 여정 지도(오늘이 놓인 자리) ④ 거리·페이스·케이던스(접힘, 펼치면 상세 — 기록은 있되 조연). 액션 3개: 한 마디 보내기(→DM) / 카드 공유(→인스타 스토리 규격) / 내일 예고("내일의 에피소드: 빗속의 드러머").
4. **여운(수 시간)**: 상대 알림 발송. 도착한 응원의 푸시는 예고만("지수가 응원을 남겼어요") — **내용 재생은 다음 러닝 시작에 이월(브리지)**. 릴레이·"당신의 리듬과 달린 사람" 알림도 이 시간대 묶음 발송(일 1회 다이제스트).
5. **다음 날**: 페이서의 노크 — 기대감 문법("어제의 응원이 기다리고 있어요. 오늘 8분 어때요?"). 죄책감 문법(스트릭 잃어요!) 금지.

【맥락 — 이월의 이유】 반응을 즉시 소모하면 도파민이 그 자리에서 끝난다. 다음 러닝의 출발선에 아껴두면 여운이 연료가 되고, 세션이 직선이 아니라 고리가 된다(⑥→① 뫼비우스).
【지표】 음성 한 마디 응답률(사연 공급률), 카드 공유율, 브리지 재생 후 완주율.

## 6. 소셜 배선 — 피드·팔로우·DM

### 6-1. 팔로우(페이스메이트)

【결정】 팔로우의 의미 = "함께 달릴 수 있는 관계"(소식 구독이 아님).
【동작】 팔로우 성립 시: 상대 러닝이 내 고스트 서랍에 들어옴 + 상대가 지금 뛰면 내 존재 레이어에 표시(라이브 합류 가능) + 상대 카드에 응원 가능. 성립 경로: ① 초대 링크 ② 공명 후 종료 카드에서 "페이스메이트 맺기" ③ 릴레이 상호 동의. 프로필 검색은 v1 미제공(관계의 입구는 함께 달린 경험).

### 6-2. 피드

【결정】 피드 = 고스트의 진열대. 모든 카드에 [이 리듬과 함께 뛰기] 버튼.
【동작】 카드 구성: 리듬 파형 + 사연 한 마디(음성 채집분) + 트랙 30초 미리듣기 + 응원 버튼 + [함께 뛰기]. 카드는 완주 시 자동 생성(작성 노력 제로), 게시 범위는 고스트 공개 범위와 동일. 피드 정렬: 페이스메이트 최신순(알고리즘 큐레이션 없음, v1).
【지표】 카드→[함께 뛰기] 전환율.

### 6-3. DM

【결정】 획득형 유지 — 맞팔 또는 함께 달린 사이(공명 이력)에서만 열림. 콜드 DM 불가.
【동작】 DM 스레드 = 러닝의 라커룸: 약속("저녁 8시에 그 에피소드 같이?") + 워키토키 조각 보관 + 종료 카드의 '한 마디' 수신 + 고스트런 알림의 답장. 신고·차단 기본 장착.
【지표】 DM 약속→세션 성사율.

## 7. 지표 트리

- **북극성: 주간 공명 세션 수** (동시+시차 공명 포함)
  - 입력 1 — 활성화: 첫 러닝 완주율 → 7일 내 첫 공명 도달률
  - 입력 2 — 빈도: 주간 세션 수/유저(에피소드+자유런), 잔향 연장률
  - 입력 3 — 관계: 초대 수락률, 공명→페이스메이트 전환율, 알림→응원 전환율
  - 입력 4 — 공급: 음성 한 마디 응답률(사연), 고스트 공개율
- **킬 조건**: 첫 공명 경험 유저의 4주 리텐션이 미경험 유저 대비 유의미하게 높지 않으면 핵심 가설 재검토.
- **가드레일 지표**: 러닝 중 화면 점등 시간(낮을수록 건강), 세션 중 이탈률, 신고 건수.
