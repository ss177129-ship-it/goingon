## 갱신

**지금 이 폴더가 정확히 그 실패 상태다** — 없는 화면을 보고 이야기하게 되는 것.
개편 UI를 되살리든 새로 그리든, 그때 캡처를 갈아엎을 것. 지금 앱의 화면을
찍어 둘 필요가 있으면 별도 폴더(`docs/design/current/`)로 나눌 것.
