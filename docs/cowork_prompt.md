## 제품 한 줄

멀리 있어도 함께 달리는 러닝앱. 발걸음이 음악이 되고, 떨어져 있는 사람과

입니다. 기록이 부끄러워 공개를 꺼리는 사람들이라, 순위·리더보드·성과 비교는
제품에서 영구히 배제합니다.

## 제가 해야 할 일 — 우선순위 순

### 1. 사업자등록 (모든 것의 선행 조건)
아래 2번 신고에 사업자등록증이 필요합니다. 1인 창조기업 기준으로
어떤 업종·형태로 등록하는 게 맞는지, 절차와 준비물을 알고 싶습니다.

### 2. 위치기반서비스사업 신고 (⚠️ 미신고 시 3년 이하 징역 또는 3천만원 이하 벌금)
러닝 앱이라 위치정보를 수집·이용합니다(좌표를 저장하지는 않지만 대상입니다).
- 접수: 과학기술정보통신부 전자민원센터(emsit.go.kr) 온라인, **비용 무료**, 최대 2주
- 소상공인·1인 창조기업 특례: 사업 개시 후 **1개월까지 유예**
- 필요 서류: 사업내용 설명자료 · 1인기업 자가진단 스크린샷 · 사업자등록증 ·
  건강보험자격득실확인서
- **신고 후 따라오는 의무**가 있습니다:
  · 위치정보 수집·이용 동의를 개인정보 동의와 **별도로** 받을 것
  · 위치정보 이용·제공 사실 확인자료를 **자동 기록하고 6개월 보존**할 것
  · **위치정보 이용약관을 따로** 둘 것(카카오·KT 방식)
  · 위치정보관리책임자 지정

→ 부탁: 신고서에 첨부할 **사업내용 설명자료 초안**과, **위치정보 이용약관
초안**을 만들어 주세요. 제출 전 체크리스트도요.

### 3. 법률 문서 마무리
개인정보처리방침·이용약관 초안에 아래 빈칸을 채워야 하고, 전문가 검토가
필요합니다.
- 사업자명 / 대표자
- 개인정보 보호책임자(성명·직위)
- 문의·신고 이메일
- 시행일

→ 부탁: 1인 창업자가 이 빈칸들을 어떻게 정하는 게 보통인지, 그리고 법률
검토를 어디서 받는 게 현실적인지(무료 법률 상담·창업지원기관 등) 알려주세요.

### 4. 도메인과 문서 호스팅
개인정보처리방침이 **공개된 웹 주소**에 올라가 있어야 합니다. App Store
등록 시 필수 입력 항목이라 없으면 제출 자체가 불가합니다.
- 도메인이 필요한 이유가 하나 더 있습니다: 나중에 '초대 링크'(친구를 앱으로
  데려오는 링크)를 만들려면 어차피 도메인이 있어야 합니다
- 예산은 최소로 하고 싶습니다

→ 부탁: 도메인 후보(브랜드에 맞는 이름), 등록처, 무료로 정적 페이지를 올릴
방법을 비교해 주세요.

### 5. App Store 제출 준비 (개발 외 영역)
- App Store Connect의 '앱 개인정보(App Privacy)' 설문 — 앱에 넣은 매니페스트와
  **답이 일치해야** 하고, 어긋나면 리젝입니다
- 앱 이름·부제·설명·키워드·스크린샷·심사 노트

→ 부탁: 스토어 등록 문구(제목·부제·설명)를 위 제품 철학에 맞게 써 주세요.
"순위·경쟁·기록 도구" 어휘는 쓰지 마세요.

### 6. 도전신청서 마무리
- 자기소개 항목에 학력·경력·수상·러닝 이력을 넣어야 합니다
- 소개 영상(66초)이 '8분 에피소드' 기능을 보여주는데, **그 기능을 최근에
  제품에서 내렸습니다.** 영상을 다시 찍을지, "앞으로 만들 범위"로 설명할지
  정해야 합니다

→ 부탁: 두 선택지의 장단점과, 심사위원이 앱을 직접 열어봤을 때 생길 수 있는
간극을 어떻게 다룰지 조언해 주세요.

### 7. 실측·검증 (제가 직접 뛰어야 하는 것)
- 걸음 리듬(케이던스) 정확도 실측: 주머니·암밴드·손에 든 상태 각 1회,
  걷기↔달리기 전환 3회 포함해서 달리기
- 두 번째 계정으로 함께 달리기 검증(혼자서는 못 하는 기능이 있습니다)

### 8. 콘텐츠 제작 (외주 판단 필요)

- 실제 러닝 녹음 100개(초기 사용자에게 보여줄 '리듬' 자산)

→ 부탁: 1인 창업자 예산으로 음악 스템을 확보하는 현실적인 방법
